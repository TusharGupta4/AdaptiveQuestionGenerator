Ans 2:
Given equation: 6x^2 - x - 2 = 0
Splitting middle term:
6x^2 - 4x + 3x - 2 = 0
2x(3x - 2) + 1(3x - 2) = 0
(2x + 1)(3x - 2) = 0
So, 2x + 1 = 0 => x = -1/2
3x - 2 = 0 => x = 2/3.
Roots are x = 2/3 and x = -1/2.
